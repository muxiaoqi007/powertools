# 报表质量规则

PowerTools 0.8.0 对 PBIP/PBIR 报表执行只读静态检查。质量中心按页面、类别和关键字浏览结果，并可把带 `targetId` 的问题定位到布局画布中的视觉对象。

## 数据范围

解析范围包括：

- 报表级、页面级、钻取和视觉级筛选器数量
- 页面尺寸、可见性、Tooltip 属性和视觉对象数量
- 视觉对象位置、尺寸、Z 层、Tab 顺序、字段、标题、替代文本和 Tooltip/钻取交互
- 书签目标对象与视觉显隐状态，用于识别动态叠放层

标题与替代文本覆盖率只统计可见、非装饰、非视觉组的数据视觉。形状、图片、文本框、按钮和导航器不会稀释覆盖率。

## 规则目录

| 规则 | 级别 | 类别 | 判断 |
|---|---|---|---|
| `REPORT-VISUAL-TITLE` | 信息 | 可访问性 | 可见数据视觉没有启用显式标题 |
| `REPORT-VISUAL-ALT-TEXT` | 信息 | 可访问性 | 可见数据视觉没有替代文本 |
| `REPORT-TAB-ORDER-EXCLUDED` | 警告 | 可访问性 | 数据视觉的 Tab 顺序小于 0 |
| `REPORT-TAB-ORDER-DUPLICATE` | 警告 | 可访问性 | 同一页多个数据视觉使用相同的非负 Tab 顺序 |
| `REPORT-VISUAL-DENSITY` | 警告 | 结构 | 单页可见数据视觉超过 18 个 |
| `REPORT-TOOLTIP-VISIBLE` | 信息 | 结构 | Tooltip 页面仍显示在普通页面导航中 |
| `REPORT-DRILLTHROUGH-BACK` | 警告 | 导航 | 钻取页没有按钮或页面导航器作为返回入口 |
| `REPORT-VISUAL-FILTER-DENSITY` | 信息 | 筛选器 | 单个视觉包含超过 4 个视觉级筛选器 |
| `REPORT-OUTSIDE-CANVAS` | 错误 | 布局 | 视觉对象超出页面画布 |
| `REPORT-DUPLICATE-VISUAL` | 警告 | 布局 | 可见对象的类型、字段、位置和尺寸完全相同 |
| `REPORT-OVERLAP` | 警告 | 布局 | 两个对象的重叠面积都超过各自面积的 50% |
| `REPORT-ALIGNMENT-GRID` | 信息 | 布局 | 至少 5 个数据视觉且 40% 以上没有贴近 8px 网格 |

## 降低误报

重复和重叠规则不检查隐藏对象、视觉组和装饰对象。书签显式控制或作为书签目标的视觉对象会被视为动态层；两个动态层之间的叠放不会报重叠，动态对象也不会进入完全重复检查。

视觉包含另一个较小对象并不自动构成重叠问题。只有重叠面积同时占两个对象一半以上才会触发，避免把图表上的卡片、切片器或按钮当成布局冲突。

## 安全边界

- 检查不会修改或删除 PBIR、TMDL、PBIX 或 Power BI Desktop 模型。
- “缺少标题”表示没有检测到启用的显式标题，不判断标题文案是否准确。
- “缺少替代文本”不等于报表不合规；替代文本仍需结合受众、语言和业务上下文人工编写。
- 自定义视觉对象或未来 PBIR 架构可能使用尚未覆盖的属性。解析失败会作为警告返回，不会写回文件。

## Power Query

`report-quality` 实体提供一行报表质量汇总；`issues` 提供逐条问题，其中 `pageName` 和 `targetId` 可用于外部质量报表中的页面/视觉定位键。字段定义见 [Power Query 接入指南](POWER_QUERY.md)。
