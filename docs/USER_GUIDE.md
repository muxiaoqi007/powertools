# PowerTools 使用指南

## 环境要求

- Windows 10/11
- .NET 8 SDK 或 .NET 8 ASP.NET Core Runtime
- 建议使用 Power BI Desktop 保存的 PBIP/PBIR 项目

## 启动

在仓库根目录运行：

```powershell
dotnet run --project .\PowerTools.csproj
```

也可以双击 `start-powertools.cmd`。应用默认打开 `http://localhost:5128`。

## 打开项目

顶部目录框支持以下路径：

- PBIP 项目根目录
- `*.Report` 目录
- `*.SemanticModel` 目录

输入本机目录后点击“打开目录”。解析在本机完成，项目文件不会上传。

## 功能导航

### 模型

- 模型对象：表、字段、层次结构和分区。
- 度量值：查看 DAX、格式字符串、显示文件夹和依赖。
- 计算组：查看优先级、计算项 DAX 和动态格式字符串。
- 模型依赖：查看度量值、字段和计算项的上下游影响。

### 关系与安全

- 关系：检查字段映射、基数、过滤方向和活动状态。
- 安全角色：检查 RLS 表筛选表达式和 OLS 对象权限。

### 书签

- 按 Power BI 保存顺序显示书签组和书签。
- 查看活动页面、应用范围、数据状态、目标视觉对象和筛选器数量。
- 查看每个视觉对象在书签中的显示、隐藏或仅目标状态。
- 如果书签引用的页面已从 PBIR 目录移除，会显示“孤立书签”提示并禁止错误预览。

### 页面布局

- 按 PBIR 中的 X/Y、宽高和 Z 层级还原页面画布。
- 可以显示或隐藏原始隐藏对象。
- 页面存在匹配书签时，可通过“书签”下拉框预览显隐状态。

### 质量检查

当前包含度量值说明、非活动关系、计算项空表达式、视觉对象越界和大面积重叠等轻量规则。

### 版本比较

输入基线项目和当前项目目录，工具会显示新增、删除和修改对象。可以按变更类型筛选或搜索对象名称。比较只生成内存报告，不会改动项目文件。

## 常见问题

### 为什么不能直接打开 PBIX？

PBIX/PBIT 是二进制容器。请先在 Power BI Desktop 中另存为 PBIP，再打开生成的项目目录。

### 为什么书签不能在画布中预览？

书签可能来自旧页面，而当前 PBIR 页面目录已经发生变化。此时工具仍展示书签状态用于审计，但不会将其套用到无关页面。

### 工具会修改模型吗？

不会。当前版本只有只读解析和本地可视化能力，不包含保存、删除或覆盖项目文件的操作。
